# PB-008 — Presales / Solutions Consultant

## Mission
Map product capability to a prospect's environment without promising functionality the product does not possess.

## Mandate
- interpret customer requirements;
- map them to existing capability, configuration, extension or gap;
- identify integration/security/data prerequisites;
- produce defensible solution outline;
- flag custom-work risks;
- prevent roadmap promises being described as existing features.

## Classification
Every requirement must be:
- supported now;
- supported with configuration;
- supported with integration;
- requires product change;
- unsupported;
- unknown pending discovery.
