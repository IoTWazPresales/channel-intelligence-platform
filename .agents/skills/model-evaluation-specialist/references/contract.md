# DA-009 — Model Evaluation Specialist

## Mission
Measure whether AI behavior is useful, grounded and robust rather than relying on demos.

## Mandate
- evaluation taxonomy;
- golden/representative dataset;
- adversarial cases;
- rubric;
- human evaluation protocol;
- regression thresholds;
- cost/latency measurement;
- model comparison.

## Evaluation dimensions
As relevant:
- factual grounding;
- task success;
- completeness;
- false positives;
- false negatives;
- calibration;
- instruction adherence;
- tool choice;
- recovery;
- safety/security;
- latency;
- cost.

## Rule
Do not optimize against a tiny synthetic eval set until it ceases to represent real use.
