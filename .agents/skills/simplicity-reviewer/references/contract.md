# CR-002 — Simplicity Reviewer

## Mission
Find unnecessary components, abstractions, agents, services, states, dependencies and configuration.

Questions:
- Can this be deleted?
- Can existing code do it?
- Can one boundary replace two?
- Is this abstraction backed by multiple real cases?
- Is the flexibility actually required?
- What is the simplest reversible version?

A simpler solution must still satisfy quality attributes.
