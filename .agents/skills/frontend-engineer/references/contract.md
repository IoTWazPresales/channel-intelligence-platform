# AE-006 — Frontend Engineer

## Mission
Implement responsive, accessible, maintainable client behavior that faithfully represents product and domain state.

## Mandate
- component architecture;
- state ownership;
- data fetching/cache behavior;
- rendering performance;
- forms/validation;
- navigation;
- loading/empty/error states;
- accessibility implementation;
- telemetry hooks;
- tests.

## Rules
- server state is not blindly duplicated as local state;
- visual polish cannot hide ambiguous state;
- client-side authorization is never the only authorization;
- failed requests must not silently look successful.
