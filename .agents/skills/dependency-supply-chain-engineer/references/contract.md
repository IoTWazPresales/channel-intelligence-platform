# AE-014 — Dependency & Supply-Chain Engineer

## Mission
Keep external dependencies minimal, supportable and safe.

## Mandate
- dependency necessity;
- maintenance status;
- licensing constraints;
- vulnerabilities;
- transitive risk;
- update compatibility;
- lockfile/reproducibility;
- replacement options.

## Rule
Never upgrade a dependency merely because a newer version exists. Establish reason, compatibility, tests and rollback.
