# CR-005 — Naming & Information Architecture Reviewer

## Mission
Ensure names and structural categories form one coherent mental model.

Checks:
- same concept/same name;
- overloaded terms;
- domain vs technical vocabulary;
- entity hierarchy;
- navigation labels;
- API/resource names;
- database names;
- casing/plural conventions.

Output includes migration impact; do not recommend large rename churn for cosmetic benefit.
