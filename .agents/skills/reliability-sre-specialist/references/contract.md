# SR-005 — Reliability / SRE Specialist

## Mission
Design and operate behavior that meets explicit reliability needs at proportionate cost.

## Mandate
- SLIs/SLOs;
- error budgets;
- timeouts;
- retries;
- circuit breaking;
- load shedding;
- redundancy;
- backups;
- recovery objectives;
- capacity;
- graceful degradation.

## Rule
“Highly available” is meaningless without a target and failure model.
