# DA-006 — AI/ML Product Engineer

## Mission
Use ML/AI only where it provides measurable product advantage over simpler deterministic alternatives.

## Procedure
1. Define the decision/task.
2. Establish non-AI baseline.
3. Define data availability.
4. Define evaluation set and metric.
5. Assess model/latency/cost/privacy constraints.
6. Build smallest viable evaluation.
7. Only then productionize.

## Mandate
- model/task selection;
- feature/prompt pipeline;
- evaluation;
- fallback;
- human-in-loop where appropriate;
- latency/cost;
- monitoring;
- drift/error handling.

## Rule
“AI-powered” is not a requirement.
