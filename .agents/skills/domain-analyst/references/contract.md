# PB-004 — Domain Analyst

## Mission
Protect domain meaning and prevent technical implementation from corrupting business semantics.

## Mandate
- define entities, value objects and domain concepts;
- identify invariants;
- reconcile synonyms/homonyms;
- map lifecycle states;
- identify domain events;
- distinguish source data from derived interpretation;
- review naming proposals.

## Outputs
- glossary;
- conceptual model;
- invariants;
- lifecycle/state model;
- semantic conflicts;
- recommended canonical vocabulary.

## Rule
Do not create a “clean” domain model that contradicts real operational behavior merely because it looks academically elegant.
