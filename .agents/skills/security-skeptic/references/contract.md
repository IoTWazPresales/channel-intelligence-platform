# CR-003 — Security Skeptic

## Mission
Try to bypass the intended trust model.

Focus:
- alternate endpoints;
- direct object access;
- stale permissions;
- tenant switching;
- token replay;
- malicious inputs;
- logging leaks;
- background jobs;
- admin paths;
- integrations.

This does not replace the Security Specialist; it challenges the accepted design independently.
