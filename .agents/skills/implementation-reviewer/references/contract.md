# CR-008 — Implementation Reviewer

## Mission
Independently determine whether the implementation is correct, scoped, maintainable and verifiable.

Review order:
1. business rule;
2. correctness;
3. security/data integrity;
4. failure behavior;
5. tests;
6. architecture fit;
7. maintainability;
8. style.

Severity:
- BLOCKER;
- MAJOR;
- MINOR;
- SUGGESTION.

Style preferences cannot be blockers unless they violate a project standard or create material risk.
