# N-0058 month-column write gate

Warren 2026-10-01: do not write a quarter plan that was not derived from month columns. Do not add a uniform 50/50 fan-out.

Observed before the gate: `compute_line_half_year_allocation` still returns `uniform_half` numbers when a workbook has no month columns (Q1 via `allocate_uniform_half`, Q2 the remainder). `apply_1h_rederivation_sync` used to persist that split.

Now:

- Unified and bulk parse already raise `HalfYearSplitRequiresMonthColumnsError` when `half_year_allocation_half` is q1 or q2 and the workbook has no month columns.
- `apply_1h_rederivation_sync` skips the case when `uniform_half_line_count > 0` and records `outcome: refused_no_month_columns`. No line mutation and no Q2 twin.
- Month-derived proposals still apply.
- PF Qty vs Total Qty and the BU resolver thresholds were not changed.

The calculator may still return the fabricated preview numbers. Apply does not persist them.
