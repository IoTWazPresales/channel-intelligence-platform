## Task failure alert

`emit_task_failure_alert` logs an error line and, when `CIP_TASK_FAILURE_ALERT_PATH` is set, appends that line to the file. It does not open a database session. `LedgerTask` calls it before `mark_task_run_failed`. The forced-failure test mocks the ledger writers.

## AI resolver

When `AI_ASSIST_ENABLED` is on and the API key or the client package is missing, `suggest_token_resolution` raises `AiResolverUnavailable`. When AI is off, it returns None. An API-call failure still logs and returns None. `AiResolverUnavailable` is not swallowed.
