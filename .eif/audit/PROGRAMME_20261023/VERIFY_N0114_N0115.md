## 5. Code review of risky points

### N-0115
- **Tenant predicate on every compiled query: HOLDS.** `compiler.py` `tenant_conds` covers three cases:
  - a base `tenant_id` column (:195);
  - tenant via a base join, for CPOR through `cpor_case` (:198);
  - tenant via `dim_product`, carried on an INNER join (:176; `tenant_conds` returns `[]` there, :197).

  Every dimension LEFT JOIN is tenant-checked (:183). The latest-SOH subquery carries tenant (:328). The rows (:387), totals (:485) and stored-period (:490) queries all start from the shared `conds` through `where_for`, and the count wraps the rows query (:473). Reference joins (:188, dim_region / dim_channel) carry no tenant predicate. That is correct: those tables have no tenant column (`app/models/dimensions.py`).
- **Ids come only from the model or v1 catalog: HOLDS.** graph.py refuses unknown measures, breakdowns, sorts and filters (e.g. :231, :275, :409), and the injection tests pass. `literal_column` is used only on constants (intervals, `UNASSIGNED`, `VOIDED_REMARK_MARKERS` at rules.py:43) and on generated output labels (`out{i}`, compiler.py:462/468).
- **Values are bound: HOLDS.** Filters, period bounds and limits are `bindparam` (compiler.py:294-317, :472).
- **v2 routes use `get_current_user`: HOLDS.** `query.py` `/v2/execute` and `/v2/explain`, and `semantics.py` `/v2/catalog`, each have `Depends(get_current_user)` in the diff.
- **Request AsyncSession: HOLDS.** `run_v2(db, ...)` uses the injected session, sets `SET LOCAL statement_timeout` and reads the scope in the same transaction (execute.py:142-143).
- **limit > 5000 refused: HOLDS for model measures** (graph.py:433-441 sets `plan.measures = []`, which gives `ok: False`). **It does not hold for governed measures: see D1.**
- **v1 unchanged: HOLDS.** The diffs of `endpoints/query.py` and `semantics.py` only add imports (`ConfigDict`, `get_current_user`), the v2 models and three new routes. `cache.py` only adds `cache_key_v2`, with a distinct prefix `cip:query:model:v1:`. The 49 v1-caller tests pass.

### N-0114
- **Formatting never alters values: HOLDS, with a caveat.** The number-integrity test (charts.test.tsx:420-) feeds values from 18.4 M down to negatives, fractions and null into all five charts under all nine units. It asserts that every hidden-table cell equals `formatChartValue(input, unit, 'full')`. That proves the values reach the formatter unscaled. The formatter itself is checked against literal strings (charts.test.tsx:184-218, e.g. `R 1.2 M`, `US$ 1.2 M`, `-R 1.2 M`). Caveat (D4): ticks, tooltips and bar labels are not covered by the integrity test.
- **No invented "Other" on bars or pies: HOLDS.** `WidgetChart.tsx` no longer calls `topWithOther`, and `chartRows.ts` adds no rows. "Other" remains only in the period by category series colour cap (widgetModel.ts:140-159), which the spec keeps.
- **Truncation: HOLDS.** The only label ellipsis left is `wrapLabel` (charts.tsx:304), after a two-line wrap, with the full name in `<title>` and the tooltip. The 14-character pre-cut (Shipping) and the 11-character cut (WidgetChart) are gone from the diff. The remaining `noWrap` / `slice(0, n)` hits in the callers are table cells and date strings, not chart labels.
