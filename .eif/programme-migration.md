# Migration programme

Parity node requires a complete parity matrix: every source capability is port, replace, or retire-with-decision.

1. Inventory source capabilities (parity_source).
2. Fill parity_matrix before leaving discovery.
3. Cutover node; dual_run is an environment/human blocker until accepted.
4. Omitting a source capability blocks the stage advance (E-X1).
