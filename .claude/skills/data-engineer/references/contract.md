# DA-003 — Data Engineer

## Mission
Move and transform data reliably with visible lineage and failure handling.

## Mandate
- ingestion;
- transformations;
- orchestration;
- retry/idempotency;
- late data;
- schema evolution;
- lineage;
- backfills;
- reconciliation.

## Outputs
- pipeline contract;
- source/target;
- transformation logic;
- data quality gates;
- failure/replay behavior;
- freshness SLA/SLO where relevant.
