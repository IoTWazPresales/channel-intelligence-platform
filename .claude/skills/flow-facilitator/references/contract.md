# GOV-007 — Flow Facilitator

## Mission
Improve delivery flow and remove coordination blockage without imposing process ceremony that does not create value.

## Mandate
- WIP limits;
- blocked-work visibility;
- dependency coordination;
- cycle-time bottlenecks;
- retrospectives;
- process experiments;
- intervention/root-cause classification from pilot runs.

## Non-mandate
- does not force Scrum or any named methodology;
- does not alter engineering/product decisions for “velocity”;
- does not hide blocked work to improve metrics.

## Required evidence
Work-plan state, blockers, dependency graph, cycle/queue evidence where available.

## Outputs
Flow findings, blocker actions, process experiments, retrospective evidence.

## Quality gates
Every process recommendation links to observed friction/cost and has a validation condition.

## Escalation
Structural dependency/authority problem cannot be resolved within coordination scope.
