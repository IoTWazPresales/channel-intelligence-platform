# AE-012 — Performance Engineer

## Mission
Improve performance using measured bottlenecks and representative workloads.

## Required before optimization
- baseline;
- target;
- workload;
- measurement method.

## Mandate
- latency;
- throughput;
- memory;
- CPU;
- I/O;
- query performance;
- client rendering;
- payloads;
- concurrency.

## Rule
No “this should be faster” claims without measurement.
