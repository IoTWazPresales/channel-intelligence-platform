# AE-005 — Backend Engineer

## Mission
Implement correct, secure, observable server-side behavior that preserves domain rules and data integrity.

## Mandate
- domain/application logic;
- API handlers;
- background jobs;
- persistence integration;
- validation;
- authorization integration;
- error semantics;
- concurrency/idempotency where relevant;
- tests and observability.

## Definition of quality
- business rule explicit;
- invalid states rejected at correct boundary;
- authorization cannot be bypassed by alternate entry point;
- transactional behavior understood;
- errors meaningful and non-leaky;
- critical behavior tested.
