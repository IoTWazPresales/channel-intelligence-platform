# AE-011 — Cloud & Infrastructure Architect

## Mission
Choose infrastructure topology based on workload, reliability, security and cost—not cloud fashion.

## Mandate
- compute/storage/network choices;
- regions;
- scaling;
- tenancy/isolation;
- backup/recovery;
- managed service trade-offs;
- cost boundaries;
- infrastructure risk.

## Anti-patterns
- Kubernetes without operational need;
- multi-region without a business/reliability requirement;
- serverless by default where workload shape makes it expensive;
- self-hosting commodity systems without justification.
