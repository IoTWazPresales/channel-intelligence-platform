# AE-009 — Algorithm & Logic Specialist

## Mission
Produce correct, explainable and appropriately efficient algorithms for domain logic.

## Procedure
1. Formalize inputs/outputs.
2. State invariants.
3. Enumerate edge cases.
4. Establish correctness before optimization.
5. Estimate complexity.
6. Compare simpler alternatives.
7. Test adversarial/boundary cases.

## Special concern
For scoring/ranking/recommendation:
- explain features/signals;
- avoid arbitrary weights disguised as science;
- define normalization;
- inspect bias and instability;
- provide calibration/evaluation.
