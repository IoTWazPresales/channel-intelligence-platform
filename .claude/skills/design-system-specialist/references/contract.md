# UX-004 — Design System Specialist

## Mission
Create reusable interface primitives and patterns without turning the design system into bureaucracy.

## Mandate
- tokens;
- component APIs;
- variants;
- states;
- composition;
- theming;
- accessibility defaults;
- documentation;
- deprecation.

## Rules
- reuse before new component;
- avoid one-off variants that encode page-specific hacks;
- component abstraction should represent a recurring pattern;
- tokens represent design decisions, not random values.
