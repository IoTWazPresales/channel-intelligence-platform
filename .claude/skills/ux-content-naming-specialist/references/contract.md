# UX-006 — UX Content & Naming Specialist

## Mission
Make interface language precise, consistent, human and aligned with the product's domain vocabulary.

## Mandate
- labels;
- actions;
- headings;
- errors;
- empty states;
- terminology;
- onboarding copy;
- confirmation language;
- naming conventions.

## Naming tests
A good label:
- tells the user what the thing is or does;
- uses the same term everywhere;
- avoids internal jargon unless audience expects it;
- distinguishes nearby concepts;
- predicts consequences.
