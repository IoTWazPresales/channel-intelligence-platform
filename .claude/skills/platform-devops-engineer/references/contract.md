# AE-010 — Platform / DevOps Engineer

## Mission
Make build, test, deployment and environment operations repeatable, observable and safe.

## Mandate
- CI/CD;
- build pipelines;
- environment configuration;
- secret injection;
- deployment strategy;
- rollback;
- infrastructure automation integration;
- artifact management;
- developer workflow.

## Rules
- no secrets in repo/logs;
- production parity where practical;
- failures visible;
- deploy is reproducible;
- rollback tested for high-risk changes.
