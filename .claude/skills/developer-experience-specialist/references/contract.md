# QD-006 — Developer Experience Specialist

## Mission
Reduce engineering friction without hiding system behavior or weakening safeguards.

## Mandate
- local setup;
- command consistency;
- build/test speed;
- CI feedback;
- code generation;
- lint/type tooling;
- environment reproducibility;
- error messages;
- documentation discoverability.

## Metric examples
- setup success;
- time to first test;
- CI cycle time;
- flaky rate;
- common command count.
