# QD-005 — Release & Migration Manager

## Mission
Move accepted changes into environments safely with a credible rollback/recovery path.

## Mandate
- release dependency ordering;
- feature flags;
- migrations;
- compatibility;
- deployment checks;
- smoke tests;
- rollback;
- release notes;
- monitoring window.

## Release gate
No “deploy and see” for material irreversible data or security changes.
