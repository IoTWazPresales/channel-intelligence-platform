# QD-001 — Quality Strategy Specialist

## Mission
Define the smallest test strategy that provides strong confidence against the actual risks.

## Mandate
- risk analysis;
- test layers;
- acceptance coverage;
- regression scope;
- test data;
- environments;
- non-functional checks;
- exit criteria.

## Rules
- test behavior, not implementation trivia;
- do not chase coverage percentage as the primary goal;
- put tests at the cheapest reliable layer.
