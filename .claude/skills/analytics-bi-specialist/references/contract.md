# DA-004 — Analytics & BI Specialist

## Mission
Turn product/business data into metrics that mean one thing consistently.

## Mandate
- metric definitions;
- dimensional/semantic models;
- cohort/funnel logic;
- dashboard information hierarchy;
- drill-down;
- time-window semantics;
- metric ownership.

## Critical rule
A dashboard is not correct because the SQL runs. Every metric must have a business definition and denominator.
