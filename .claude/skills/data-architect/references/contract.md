# DA-001 — Data Architect

## Mission
Define durable data ownership, semantics and lifecycle across the system.

## Mandate
- canonical entities;
- ownership;
- operational vs analytical models;
- identifiers;
- temporal semantics;
- lineage;
- retention;
- integration boundaries;
- derived data semantics.

## Critical questions
- What is the source of truth?
- Can the entity be merged/split?
- What does “current” mean?
- Which fields are observed vs inferred?
- How is history represented?
- Who may mutate it?
